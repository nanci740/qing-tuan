# 内阴影、主题按钮与自定义选择框

基于 main a7ba4fe。

- 上轮整理把播放器、宠物屏幕左上凹陷从原来的 70% 淡化为 22%。本次恢复清晰凹陷：`--effect-inner-emphasis` 从正文青灰派生 70%，仍属于内侧暗边用途。转盘补同源内阴影，圆形按钮保留原斜面与按下效果。
- `--effect-face-accent` 集中定义世界书主题按钮原有的 55% / 42.5% / 56.5% / 88% 渐变。主要主题按钮、聊天发送按钮、确认按钮复用这个渐变，不改白色次要按钮和豆沙红危险操作。播放器及宠物圆形按钮图标用 `--color-accent`，白色亮面保留。
- 回复长度、引用方式、时间显示、转写类型改用 RetroSelect，复用现有 ChoiceProvider 与古早选项弹窗；原值与保存回调保留。其余 API/MCP/世界书隐藏 select 继续作为原自定义界面的兼容字段。
- ChoiceProvider 支持空字符串选项，修复“沿用语音连接”无法确认；增加键盘焦点循环、关闭返回触发器和弹窗名称。
- 电量填充与外框统一为 `--color-text`。电量宽度、实时更新与原模拟后备逻辑保留，清除不再使用的深灰/红/绿电量色状态。

验证：构建；ui-controls-regression 62 项（3 主题、实际转发与字体区域、选择确认/取消、空值、Escape、持久化、电量与图标用色）；color-system-regression 123 项；image-cleanup-regression 24 项。共 209 项通过。

新文件 RetroSelect.tsx 必须与调用方一同合并。样式原声明直接替换，新触发器只添加布局规则，无新的覆盖皮肤。无依赖变更、无存储格式变更。

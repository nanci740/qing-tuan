# 完整迁移验证说明

全部旧运行模块已由 React + TypeScript 替代，类型检查、生产构建和迁移结构校验通过。所有 17 份 CSS 与基线逐字节一致；4357 个样式片段的顺序保留。

本次复查当前构建与原版的消息操作、多选转发、记录详情与存储、置顶、消息几何、请求回复、聊天切换与历史恢复、导入导出、设置与外观，以及其他在 validation-summary.json 的 latest_group_suites 中列出的专项。每项直接比较 DOM、计算样式 / 尺寸、表单实际值、localStorage；资源场景也比较 IndexedDB。

新增媒体与聊天室测试覆盖录音状态、文字草稿保留、拒绝麦克风权限、2 MiB 超限、返回时取消、30 秒自动发送，以及历史搜索的大小写、结果跳转、高亮、无结果与 Escape，快捷操作与关闭。新增世界书 / 回忆照片测试覆盖关联保存、角色间独立关联、恢复和照片压缩与持久化。语音识别 / 翻译请求结果、缓存转写和语音播放状态也在消息操作 / 回复专项中验证。

为比较移除旧脚本后的页面，快照排除 SCRIPT 节点，合并相邻文本节点。React 受控输入反射的默认值属性允许不同，实际值仍由 formState 严格比较。静态中文注释、消息内容、未知导入属性、布局、CSS、原始持久化数据不作宽松处理。少量截图是否字节一致在每个检查项明确记录。

外部资源在两版中采用相同屏蔽策略；API、录音和合成语音使用确定性模拟。真实服务的 Key、网络和硬件能力需在运行环境提供。

历史报告记录此前构建，不能把它们的旧“未完成”描述当作本版状态。当前完成状态以 README 与 migration-manifest.json 为准。

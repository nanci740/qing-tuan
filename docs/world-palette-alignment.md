# 世界书配色基准与聊天样式合并

基于 main ee872e0（七类配色与四类光影均已合并）。世界书现有颜色公式保留，所有主题继续动态派生，未写死青色 HEX。

- 主画面、播放器文字采用和世界书标题正文相同的 `--color-text`，次级文字采用 `--color-muted`。
- 29 处普通说明、预览文字和输入提示不再另混白色；删除、错误、禁用和交互态保留语义。
- 转发页与列表、聊天室、聊天设置共用顶栏渐变与白字规则，移除旧独立渐变及描边标题。返回箭头、按钮尺寸、内容边距对齐聊天室，保留多选、搜索、转发行为。
- 聊天设置的字体 DEFAULT 标牌复用美化设置方形印章样式；“载入”复用现有聊天字体按钮样式，不新增覆盖层。
- 搜索输入提示统一简体。

验证：构建；color-system-regression 123 项；chat-style-regression 26 项（3 主题，实际发送、转发、多选、返回、打开字体区域、检查按钮与标牌、320px 窄屏）。

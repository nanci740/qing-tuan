# 聊天设置独立下拉按钮与图片清理图标

基于 main 3195544。此前图片清理收简、按钮斜面统一已合并。

- 聊天设置的 RetroSelect 改为非按钮值框与独立方形箭头按钮。箭头按钮使用统一亮面与一亮一暗斜面，三角居中，点击/键盘打开选择弹窗。值框不再被 useButtonPress 标记，按箭头不会移动文字框或设置分组。
- 其他页面的 RetroSelect 保持原自定义选择入口。
- 图片清理标题栏添加线条图片图标与有实际关闭行为的叉号按钮；通过 DataManagement 的 onClose 返回设置。旁边的大图标由像素路径改为平滑线条图片叠层图标，继续随主题换色。
- 修改已有组件和原样式规则，移除旧的单边分隔式箭头外观，不追加覆盖皮肤。

验证：npm run build；ui-controls-regression 128 项（三主题，实际鼠标按下保持值框与分组不动、仅箭头反馈、选项保存/取消、Escape 焦点返回）；image-cleanup-regression 26 项（关闭重开及原清理逻辑）；390px 截图检查。合计 154 项通过。

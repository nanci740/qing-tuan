# 设置控件字号与对齐修复

基于 main c312bb5。修改现有规则，并移除旧箭头绘制；不叠加独立皮肤。

- RetroSelect 不再使用 font 简写覆盖页面字号；转写类型复用 vi-choice-btn，字号与输入框一致。
- API、语音、生图的模型获取入口共用居中的实心三角，保留获取模型、加载禁用及弹窗逻辑。
- 聊天设置采用独立方形箭头区域与 SVG 三角，去掉原背景拼接箭头；长标签省略，不挤压箭头。
- 添加角色提示的加号改为 SVG，方形按钮采用 grid 居中，不受字体基线影响。
- 共用选项弹窗采用聊天删除确认框的宽度、标题栏、底色、边框与外阴影；保留单选列表、取消/确定、Escape 与焦点返回。

验证：npm run build；ui-controls-regression 83 项（三种主题，包含字号、箭头/加号居中、弹窗与保存取消行为）；color-system-regression。

将压缩包内的 src、scripts、docs 同名文件合并到仓库，构建后提交。dist 不包含在补丁中。

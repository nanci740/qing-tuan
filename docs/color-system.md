# 青团机配色

界面颜色以 `src/styles/tokens.css` 顶部七类用途为准。页面变量（如 `--set-title`、`--cr-title`）保留为兼容别名，避免组件与用户 CSS 失去已有接口。不要在页面末尾新增另一组颜色来覆盖旧颜色。

| 用途 | 变量 | 使用范围 |
| --- | --- | --- |
| 主色 | `--color-primary` | 柔化后的主题色，装饰及材质来源 |
| 强调色 | `--color-accent` | 主按钮及选中状态 |
| 标题和正文 | `--color-text` | 标题、正文、输入文字、普通按钮文字 |
| 说明和边框 | `--color-muted` | 说明、提示、普通边框 |
| 页面底色 | `--color-page` | 白色中混入少量主题色 |
| 卡片和输入框 | `--color-surface` | 固定纯白；白色按钮字及高光也取此值 |
| 删除和错误 | `--color-danger` | 豆沙红操作及错误状态 |

`--theme-accent` 保留用户选择的原色，`--theme-color` 保留现有柔化框架色计算。用户的选色、默认色、保存方式和换色入口未改。`--color-*` 在根节点和 body 重新计算，避免子页面继承原色计算结果而与柔化主题不一致。

`--color-accent-strong`、`--color-tint`、`--color-divider`、`--color-paper`、`--color-danger-ink` 等是上述用途的派生层次。需要调节全站颜色时，在这一处修改派生公式，不要复制到每个页面。

## 高光和阴影

本次统一颜色来源，保留现有材质与交互。设置按钮仍为平涂正面，主画面和世界书仍可有渐变高光；斜面、按下内凹和右下硬阴影继续保留。阴影中的普通固定蓝灰、黑灰改用主题派生颜色，白色高光保持原透明度。纸张叠层、玻璃和金属仍保留各自的层次与布局。

## 有意保留的颜色

调色盘候选颜色、世界书分类标签、离开等状态色，以及喜欢/不喜欢的区分属于功能内容，不强行合成同一色。SVG 遮罩的黑色控制透明度，不是页面显示的黑色。用户保存的自定义气泡 CSS、导出文档、用户图片和头像未改。普通错误和危险操作已归到豆沙红派生色。

## 验证

- 所有 CSS 可解析，修复了此前美化按钮选择器缺少开括号的两处规则。
- 构建通过。
- 配色检查 97 项：青色、粉色、较深青色；13 个页面或弹窗的颜色与基线布局；320px 窄屏；实际选色保存与刷新恢复。
- 图片清理 24 项、设置保存 33 项、档案/世界书导入 25 项通过。

浏览器检查脚本是 `scripts/color-system-regression.mjs`。需要现有测试环境的 Playwright 与 Chromium；可用 `QT_TEST_RUNTIME` 和 `CHROMIUM_EXECUTABLE` 指定。可选 `QT_COLOR_BASELINE` 指向整理前构建的 dist，才会执行基线布局对比。运行检查前先运行 `npm run build`。
